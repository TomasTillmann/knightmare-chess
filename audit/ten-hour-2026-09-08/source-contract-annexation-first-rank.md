# Annexation and first-rank en passant — source-only review

Status: qualified source ambiguity; no engine or test sources inspected.

The card text explicitly preserves en-passant vulnerability for a Pawn moved from its starting square. Local rules §13.5 repeats this condition using orientation-adjusted starting squares. Neither text explicitly says that a first-rank square counts as a starting square, or explicitly prohibits en passant from another origin.

The publisher FAQ page 7 expressly permits any Pawn on its owner's first or second rank to move two clear squares regardless of prior movement, and makes that move vulnerable to an appropriately placed enemy Pawn's en-passant capture. Local §13.1 repeats this general rule. Applying its broad wording to Annexation suggests that an eligible first-rank two-square advance remains vulnerable, but the FAQ answer does not name Annexation. This is an inference rather than an explicit card-specific ruling.

For second-rank origins, the sources strongly support vulnerability even if a Pawn previously moved or returned there. Treating “starting square” as only that physical Pawn's exact original file would create a history-dependent exception that these inspected sources never state; the FAQ expressly removes prior-movement dependence. A cross-file second-rank origin is therefore supported by the general rule, though the card's singular phrase leaves its literal physical-square interpretation unstated.

Recommended audit classification: record first-rank Annexation as an unresolved general-rule/card-wording interaction. Do not label either outcome an unequivocal publisher violation from these sources alone. Record second-rank vulnerability as the stronger control, including a Pawn previously moved onto another second-rank file.

Sources read: cards.md Annexation; rules.md §§13.1, 13.3, 13.5; local publisher PDF official-faq.pdf page 7; one full-PDF Annexation keyword search, whose hits concern Confabulation and New Tactics rather than this en-passant issue. No external browsing; no engine execution.

## Independent local wording check

Section 13.1 explicitly permits first- and second-rank two-square moves and en passant after “such a move.” Section 13.5 guarantees vulnerability from an orientation-adjusted starting square, but does not state whether this is exhaustive or whether first-rank Annexation qualifies under §13.1. Connecting the general rule to this card therefore requires interpretation; neither inspected passage explicitly settles first-rank Annexation.
